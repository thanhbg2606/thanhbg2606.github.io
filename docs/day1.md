# Bài 1: Nhập môn Lập trình

Chào mừng bạn đến với hành trình 10 ngày trở thành lập trình viên!

## Mục tiêu bài học
- Hiểu lập trình là gì.
- Cài đặt môi trường làm việc cơ bản.
- Viết chương trình đầu tiên.

## Lập trình là gì?
Lập trình là cách chúng ta giao tiếp với máy tính để yêu cầu nó thực hiện các công việc theo ý muốn.

```javascript
console.log("Chào thế giới!");
```

### Bài tập về nhà
1. Cài đặt VS Code.
2. Thử tạo một file `index.html` đơn giản.
